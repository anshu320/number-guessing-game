# 🎯 Number Guessing Game

A fun and simple **Number Guessing Game** built with **HTML, CSS, and JavaScript**.

The computer randomly selects a number between **1 and 100**, and you have **10 attempts** to guess it correctly. After every guess, the game tells you whether your guess was too high or too low.

👉 **[Play the Game](https://anshu320.github.io/number-guessing-game/)**

## ✨ Features

- 🎲 Random number generated between 1–100
- 🔢 Maximum of 10 attempts
- ⬆️ Hint when the guess is too high
- ⬇️ Hint when the guess is too low
- 🏆 Winning message when the number is guessed
- ❌ Game over after 10 incorrect attempts
- 🔄 Start a new game option
- 🎨 Simple and clean interface

## 🎯 How to Play

1. Enter a number between **1 and 100**.
2. Click the **Guess** button.
3. Read the hint to find out if your guess is too high or too low.
4. Keep guessing until you find the correct number.
5. You have **10 attempts** to win.
6. Start a new game and try again! 🎮
